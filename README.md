# ⚔️ HERO IN EXILE - Pro Action Game

An exiled prince fights to reclaim his kingdom. A complete 3-level action game built with HTML, CSS, and JavaScript.

### 🎮 Play Live
Play the game here: https://vignesh2921.github.io/hero-in-exile/

### 🏆 Features
- 3 Levels: Defeat 5, 7, 10 Enemies
- Win Condition: Clear All 3 Levels To Reach Kingdom
- Lose Condition: HP Becomes 0
- HP System: Touch Damage, Pass Penalty -10, Hit Damage -15, Level Bonus +20
- Score System: +10 Per Kill, +50 Level Bonus, +100 Win Bonus

### 🕹️ How To Play
- **Left / Right Arrow** - Move Hero
- **Space** - Sword Attack
- **Up Arrow** - Jump To Dodge Enemy Attack

### 📜 Story
Prince Arjun was exiled from his kingdom. Enemies are guarding the kingdom. Defeat all enemies in 3 levels to reclaim the throne and become the King.

### 🛠️ Tech Used
- HTML - Game Structure
- CSS - Game Design & UI
- JavaScript - Game Logic, HP System, Level System
- Canvas API - Game Rendering
